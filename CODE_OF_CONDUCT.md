# Code of Conduct / Davranış Kuralları

**EN** — We want Needle's issue tracker, pull requests and discussions to be a
welcoming place for everyone. The following rules apply to all project spaces.

**TR** — Needle'ın issue, pull request ve tartışma alanlarının herkes için
kusursuz olmasını istiyoruz. Aşağıdaki kurallar projenin tüm alanlarında geçerlidir.

## Our standards / Beklenen davranış

- Be respectful and constructive. / Saygılı ve yapıcı olun.
- Assume good intent; ask for clarification before assuming the worst.
  / İyi niyet varsayın; olumsuz yorum yapmadan önce açıklama isteyin.
- Give actionable feedback and accept it gracefully. / Geri bildirimi
  uygulanabilir biçimde verin ve nazikçe karşılayın.
- Respect different experience levels, languages and time zones. / Farklı
  deneyim seviyelerine, dillere ve saat dilimlerine saygı gösterin.

## Unacceptable behaviour / Kabul edilmeyen davranış

- Harassment, insults, personal attacks or discriminatory language.
  / Taciz, hakaret, kişisel saldırı veya ayrımcı dil.
- Publishing someone else's private information without permission.
  / Birinin özel bilgilerini izinsiz yayımlamak.
- Trolling, deliberate disruption or sustained off-topic arguments.
  / Trolling, kasıtlı engelleme veya uzun süre konu dışı tartışma.
- Impersonating maintainers or misrepresenting the project.
  / Bakımcı gibi davranmak veya projeyi yanlış tanıtmak.

## Scope / Kapsam

This applies to issues, pull requests, code reviews, discussions, and any
public space where someone represents Needle. / Issue'lar, pull request'ler,
kod incelemeleri, tartışmalar ve birinin Needle'ı temsil ettiği tüm herkese açık
alanlar kapsamdadır.

## Enforcement / Uygulama

Maintainers may edit or remove comments, close issues, or temporarily/permanently
restrict participation when these rules are broken. Reports can be sent
privately through GitHub's "Report a vulnerability" form on the Security tab
with a note that it concerns conduct, or by opening a confidential report to
the repository maintainers. All reports are reviewed fairly and confidentially.
/ Bu kurallar ihlal edildiğinde bakımcılar yorumları düzeltebilir/silebilir,
issue'ları kapatabilir veya katılımı geçici/sürekli kısıtlayabilir. Bildirimler
Güvenlik sekmesindeki "Report a vulnerability" formu üzerinden (davranış
konusunda olduğu belirtilerek) ya da depo bakımcılarına özel olarak
iletilebilir. Tüm bildirimler adil ve gizli biçimde incelenir.
